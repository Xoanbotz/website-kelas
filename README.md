# X PPLG — Class Digital Archive
Buka `index.html` langsung di browser atau deploy ke hosting statis (GitHub Pages, Netlify).

## Yang perlu kamu ganti
- Foto kelas: `assets/images/class/class-photo.jpg`
- Foto siswa: `assets/images/members/student-01.jpg` … `student-33.jpg`
- Data siswa: `data/students.js` (nama, panggilan, lagu, artis, `musicUrl` Spotify/YouTube Music, `coverUrl`, `bio`)
- Galeri: `data/memories.js` + foto di `assets/images/memories/`
- Motto dan deskripsi kelas: bagian `#about` di `index.html`

Musik hanya dibuka lewat tautan resmi (Spotify/YouTube Music). Tidak ada file audio di proyek ini.
Gambar yang belum ada otomatis diganti placeholder.
